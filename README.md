# Store Performance Analysis

## 📊 Project Overview

This project analyzes the performance of 896 stores using Power BI.

The dashboard provides an overview of store sales, customer activity, store area, and item availability to identify high-performing and underperforming stores.

## 🎯 Objectives

- Analyze overall store performance
- Identify the top-performing stores by sales
- Identify the lowest-performing stores
- Analyze stores with the highest number of customers
- Examine the relationship between store area, items, and sales
- Provide an interactive dashboard for performance analysis

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📌 Key KPIs

- Total Stores: 896
- Average Store Area: 1.49K
- Average Items: 1.78K
- Average Sales: 59K
- Average Daily Customers: 786

## 📈 Dashboard Features

- Top 10 Stores by Sales
- Bottom 10 Stores by Sales
- Top 10 Stores by Customers
- Store Area filter
- Store ID filter
- Sales and Item analysis

## 💡 Key Insights

The dashboard helps identify significant differences in sales and customer activity across stores.

The top-performing stores generate considerably higher sales than the lowest-performing stores, while customer activity also varies significantly between locations.

These insights can help businesses identify high-performing locations and investigate underperforming stores for potential improvement opportunities.
